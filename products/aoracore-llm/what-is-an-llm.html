What is an LLM

aoracore-llm · Concept

Definition

An LLM (large language model) is a computer program that has learned the patterns of language by reading a huge amount of text. When you give it some text, it predicts what is most likely to come next, one small piece (called a token) at a time. Repeating that prediction over and over is how it writes answers, summaries and code.

Analogy

An LLM is like the autocomplete on your phone keyboard, only far more capable. Your phone suggests the next word from the last few words you typed. An LLM does the same thing from whole pages of text, which is why it can finish an essay and not just a sentence.

Example code

This Python snippet downloads a small, free model and asks it to continue a sentence.

# First, in a terminal: pip install transformers torch
from transformers import pipeline

# Load a small model that runs on a normal laptop
generator = pipeline("text-generation", model="distilgpt2")

# Ask it to continue the sentence with up to 5 new tokens
result = generator("The sky is", max_new_tokens=5)
print(result[0]["generated_text"])

It prints your sentence plus a few new words. Run it twice and the ending will usually be different.

Common mistakes

  • Thinking it looks things up. An LLM writes text that sounds likely. It does not check facts unless it is connected to a search tool, so it can be confidently wrong.
  • Thinking it remembers you. The model only sees the text in the current conversation. Anything outside that text is unknown to it.
  • Expecting the same answer every time. The model picks the next token with a little randomness, so the same question can get different answers.

Interview question

In simple terms, how does an LLM produce a response to a prompt?

It splits the prompt into tokens, then predicts how likely each possible next token is and picks one. It adds that token to the text and repeats until the answer is complete. It learned to make these predictions by training on a very large amount of text.

Quiz

Pick an option to see the answer.

1. What does an LLM do at each step when it writes an answer?

An LLM builds its answer one token at a time by predicting what is most likely to come next.

2. What is a token?

Tokens are the small pieces of text a model reads and writes. A short word is often one token, and a long word can be several.

3. Why can an LLM give a confident answer that is wrong?

The model predicts likely text. Likely text is often true, but nothing in the model checks that it is.
